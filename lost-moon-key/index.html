Two observers · Replay variations

두 관측자의 달 서고

한 명은 별지기로 등불을 살피고, 다른 한 명은 기록지기로 서고 규칙을 읽어요. 어른·아이 대신 하고 싶은 역할을 나누세요. 두 관측을 말로 합쳐 아홉 열쇠 중 하나를 고릅니다.

한 기기를 번갈아 보며 현재 관측 판을 함께 풀어요. 역할을 볼 때 상대는 화면을 보지 않고, 중립 인계 화면에서 기기를 건네세요. 화면 구분은 놀이 규칙이며 비밀을 보장하는 보안 기능은 아닙니다. 설치·인쇄·타이머·특별한 준비물은 필요 없습니다.

원래 네 숫자 문제와 별개의 방입니다. 위 보호자 정답·기존 PDF·인쇄판에는 이 방이 들어 있지 않습니다. 첫 관측은 항상 같습니다. ‘현재 판 다시 시작’은 같은 단서를 유지하고, ‘새 관측으로 바꾸기’는 직전과 다른 정답의 관측·규칙 조합으로 바꿉니다. 조합은 제한되어 이후 반복될 수 있습니다.

중립 인계 화면

단서를 가렸습니다. 기기를 건네고, 맡은 역할만 열어 보세요. 각자 알아낸 색·수와 해석 규칙을 말로 나누세요.

별지기의 관측

등불 색은 같은 세 색 순서가 반복됩니다. 다음 칸의 색을 알아내세요.

파랑 → 노랑 → 보라 → 파랑 → 노랑 → ?

아래에서 준비됨만 세세요. 도형과 청소 중인 등불에 속지 마세요.

  • ★ 별 등불 — 준비됨
  • ☾ 달 등불 — 청소 중
  • ★ 별 등불 — 준비됨
  • ● 원 등불 — 준비됨
  • ★ 별 등불 — 청소 중

다음 색과 준비된 수를 기록지기에게 말해 주세요. 열쇠 도형으로 바꾸는 규칙은 이 관측대에 없습니다.

기록지기의 해석

서고의 기록을 읽고 별지기가 전한 준비된 등불 수를 열쇠 도형으로 바꾸세요. 등불에 그려진 도형을 그대로 고르는 규칙이 아닙니다.

하나도 준비되지 않음 → ★ 별

하나 이상이며 둘씩 짝지어 남지 않음 → ● 원

둘씩 짝지으면 하나 남음 → ☾ 달

수와 짝짓기 규칙을 함께 해석하세요. 실제 등불 색과 준비된 수는 이 기록대에서 보이지 않습니다. 별지기에게 물어보세요.

현재 역할 단서 카드

관측 표시가 같은 두 카드를 사용하세요. 새 관측에서는 두 카드 모두 다시 준비하세요. 이미 저장·전달한 파일은 회수되지 않습니다. 파일 전달은 직접 하며 자동 전송·동기화는 없습니다. 최종 열쇠 선택은 원래 진행 기기에서 하세요.

역할 TXT 직접 저장

함께 고르는 열쇠

별지기가 찾은 다음 색, 두 사람이 등불 수를 규칙에 맞춰 해석한 도형을 합쳐 고르세요. 역할 단서를 다시 볼 때는 중립 화면에서 돌아갑니다.

색 이름 + 도형 이름으로 열쇠 하나 선택

두 역할의 단서를 나눠 읽고, 서로 알아낸 것을 말해 주세요.

두 관측이 한 이야기를 열었어요

보라빛 달 열쇠가 서고 문에 꼭 맞습니다. 별지기의 관측과 기록지기의 해석이 만나, 닫혀 있던 달 도서관의 작은 창이 열렸어요.

창가에서 잠들었던 이야기가 두 사람에게 속삭입니다. “하늘을 본 사람과 기록을 읽은 사람이 함께 와 주었구나. 오늘의 첫 문장을 같이 시작해 볼래?”

Paper and a pencil only. No lock, timer, or special props are needed.

How to host / 진행 방법

Give the player pages only. Ask the player to solve the four clues in order and write one digit for each clue. Put the four digits together for the final code.

플레이어용 페이지만 건네세요. 네 문제를 순서대로 풀어 각 문제에서 한 자리 숫자를 찾고, 마지막에 네 숫자를 이어 암호를 만들게 합니다.

Two-step hints / 두 단계 힌트

1. Star Shelf / 별 선반

Ignore the other shapes. / 다른 도형은 무시하세요.

Point to each star one at a time. / 별을 하나씩 짚어 보세요.

2. Lamp Pattern / 등불 규칙

Compare the first three lamps with the repeat. / 처음 세 등불과 다음 반복을 비교하세요.

After MOON comes STAR. What is STAR's number? / MOON 다음은 STAR예요. STAR의 번호는 무엇일까요?

3. Story Calendar / 이야기 달력

Move one day after Wednesday. / 수요일에서 하루 뒤로 가세요.

Find Thursday. / 목요일을 찾으세요.

4. Ready Buttons / 준비 단추

Leave out the two that need cleaning. / 청소가 필요한 두 개는 빼세요.

Calculate 4 - 2. / 4 - 2를 계산하세요.
