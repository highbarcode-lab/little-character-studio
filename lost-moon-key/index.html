Mission / 미션

Every night, the Moon Library sends one bedtime story into the sky. Tonight, the key to the story box is gone. Solve the four clues in order. Each clue gives one digit. Put the digits together to open the box.

매일 밤 달 도서관은 잠자리 이야기를 하나씩 하늘로 보냅니다. 그런데 오늘은 이야기 상자의 열쇠가 사라졌어요. 네 단서를 순서대로 풀어 한 자리 숫자를 하나씩 찾고, 네 숫자를 이어 상자를 여세요.

Parent guide / 보호자 안내

Lost Moon Key

Prepare / 준비

Paper and a pencil only. No lock, timer, or special props are needed.

종이와 연필만 준비하세요. 자물쇠, 타이머, 특별한 소품은 필요하지 않습니다.

How to host / 진행 방법

Give the player pages only. Ask the player to solve the four clues in order and write one digit for each clue. Put the four digits together for the final code.

플레이어용 페이지만 건네세요. 네 문제를 순서대로 풀어 각 문제에서 한 자리 숫자를 찾고, 마지막에 네 숫자를 이어 암호를 만들게 합니다.

Read a hint aloud whenever it helps. There is no penalty for using hints.

필요하면 언제든 힌트를 읽어 주세요. 힌트를 써도 벌칙은 없습니다.

Use terms / 사용 조건

The purchaser may print and use this file at home or in one group or class they directly host. The original file may not be redistributed or resold.

구매자는 가정 또는 직접 여는 모임/수업 한 곳에서 인쇄해 사용할 수 있습니다. 원본 파일의 재배포와 재판매는 허용되지 않습니다.

Digital files only. No physical item or gift is included.

디지털 파일만 제공되며 실물이나 선물은 포함되지 않습니다.

Parent guide / 보호자 안내

Hints + Answer Key

★

Two-step hints / 두 단계 힌트

1. Star Shelf / 별 선반

Ignore the other shapes. / 다른 도형은 무시하세요.

Point to each star one at a time. / 별을 하나씩 짚어 보세요.

2. Lamp Pattern / 등불 규칙

Compare the first three lamps with the repeat. / 처음 세 등불과 다음 반복을 비교하세요.

After MOON comes STAR. What is STAR's number? / MOON 다음은 STAR예요. STAR의 번호는 무엇일까요?

3. Story Calendar / 이야기 달력

Move one day after Wednesday. / 수요일에서 하루 뒤로 가세요.

Find Thursday. / 목요일을 찾으세요.

4. Ready Buttons / 준비 단추

Leave out the two that need cleaning. / 청소가 필요한 두 개는 빼세요.

Calculate 4 - 2. / 4 - 2를 계산하세요.
