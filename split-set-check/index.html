1. 분할 파일 고르기

여러 묶음을 한 번에 선택하세요. 같은 이름도 상대폴더가 다르면 분리합니다.

지원: .partNN.rar · .7z.NNN · .zip.NNN
일반 파일 선택은 폴더 정보를 제공하지 않습니다. 서로 다른 폴더는 ‘폴더 선택’으로 공통 상위 폴더를 고르세요.

지원 범위와 한도

legacy .rar/.r00, .z01/.zip, 모호한 .001 등은 미인식으로 표시합니다. 대소문자가 다른 이름은 별도 묶음으로 남깁니다. 번호 자릿수 혼재는 경고하고 01과 001은 같은 번호의 중복으로 잡습니다.

한 번에 2,000개·100묶음, 이름 512자·상대경로 1,024자, 번호 1–999,999,999. 목록은 묶음당 앞 120개, 범위는 앞 120구간, 결과 텍스트는 200,000자까지 표시하며 생략을 알립니다. 선택 파일은 변경하지 않습니다.

파일을 선택하거나 예시로 시작하세요.
